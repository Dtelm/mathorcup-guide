# A2 路线：有基础 × 独立完成

你打过比赛，知道怎么做，但这次只有你一个人。没人帮你看代码、没人帮你验证结果。

这条线就做两件事：**让 Codex 当你的第二双眼睛**，**管住一个人容易失控的地方**。

单人三机制，先记死：

1. **强制反对**——三个定稿点：选题、模型定稿、论文定稿。每个点让 Codex 挑三个毛病。听了不一定改，但必须听。
2. **止损线**——只限三个大任务：选题（当晚 23:00）、建模（第 3 天中午 12:00）、调优（最多 4 小时）。到点没成，走止损三步：换做法 → 降级目标 → 砍掉。
3. **范围控制**——选题当晚写"不做什么"清单。比赛期间想加东西，先删掉清单里一样。

决策卡用简化版：决策一行 + Codex 反对意见一行 + 自己点通过。只在选题、换题、提交前确认三个时刻出现。

每次用 AI 记一笔：工具、问了什么、怎么用的。最后要交《AI工具使用详情.pdf》，漏报等于没报。

> 加分菜单是锦上添花。时间不够，优先砍它——它就是"不做什么"清单的头号候选。

---

## 赛前

- 备齐：Codex（或任意 AI 工具）、论文模板、一个文档（时间表、砍范围清单、决策卡都写里面）
- 排 7 天时间表，把三个止损线写进去
- 立三条单人规矩：① 每天固定作息，一个人没有队友拽着，作息就是纪律 ② 大决策过决策卡 ③ 卡住 2 小时就喊 Codex

### 🤖 发给 AI：赛前试走一遍流程

```
我是参加 MathorCup 大数据竞赛的选手，有建模比赛经验，这次一个人参赛，今年赛题还没公布。
这是去年赛题：[贴赛题]
请带我模拟走一遍流程：从选题、建模、编程到写论文，每一步该做什么、产出什么、大概花多少时间。
一个人做，我想提前知道哪里最容易超时，不用真的做题。
```

> 💡 加分菜单：翻出去年赛题的获奖论文，挑一篇，记一个"评委看了会亮眼"的方向。不抄，只记方向。

---

## 第 1 晚：选题 + 砍范围清单（10/23 18:00 赛题公布）

赛题公布后，先读 3 小时：数据长什么样、评分标准、哪几题可做，都过一遍。一个人更要读全。

### 🤖 发给 AI：选题利弊分析

```
我独立读了赛题，我的选题倾向和理由是：
[贴你的倾向和理由]
请做利弊分析：数据好不好处理、模型可不可行、写论文的坑在哪。
不要给结论，不要推荐，我自己决定。
```

定了倾向之后、定稿之前——**强制反对①**：

### 🤖 发给 AI：选题强制反对

```
我准备选 ____ 题，理由是 ____。
请挑三个毛病：数据、时间、可行性各找一个。只挑毛病，不夸，不推荐别的题。
```

听完毛病，你再决定。决定完，过决策卡：

```
【决策卡】选题
决策内容：选 ____ 题，因为 ____
Codex 反对意见（记录一行）：
自己点通过：□
```

然后写**砍范围清单**：

```
【不做什么】
1. 不做 ____（本来想做，砍了）
2. 不做 ____
```

比赛期间想加东西，先删掉清单里一样。一个人最容易越做越大——这张清单就是你的刹车。

> 💡 加分菜单：看官方评分标准（论文、可运行代码、泛化性能、创新性），挑一个评分点做差异化，写进选题理由。

---

## 第 2 天：建模（止损线：第 3 天中午 12:00）

数据清洗 + 建模方案，一天。今晚睡前把进度发给 Codex：

### 🤖 发给 AI：风险提示

```
这是我今天的进度和明天的计划：
[贴你今天的产出]
请找出风险点：哪里可能比想象的花时间、我明天最可能卡在哪。
只列风险，不用给方案。
```

---

## 第 3 天：建模收尾 + 编程开工

**中午 12:00 止损线。**到点还没有能跑的模型，走止损三步：

1. 换做法：换更简单的模型
2. 降级目标：先用现成基线模型跑通，别追求效果
3. 砍掉：直接用赛题附带的基线（如果有），把时间让给论文

止损线不是认输，是把时间花在能交卷的地方。

定稿前——**强制反对②**：

### 🤖 发给 AI：模型强制反对

```
这是我的模型方案，今天要定稿：
[贴方案]
请挑三个毛病：数据有没有漏洞、假设站不站得住、评委可能会问什么。
只挑毛病，我改完再定稿。
```

下午编程开工：**跑通优先于调优**。代码报错就发给 Codex：

### 🤖 发给 AI：代码报错

```
代码报错，报错信息：
[贴报错]
相关代码：
[贴代码]
我用了什么数据、想干什么：[一句话]
请先说人话解释为什么报错，再给修复方法。
```

> 💡 加分菜单：同一个指标，多给评委一个对比视角。比如不只报准确率，还报"和朴素模型的提升幅度"。时间够才做。

---

## 第 4 天：编程主攻 + 论文开写

论文不要堆到最后两天。今天把框架搭起来，方法部分边做边写。报错即问 Codex（用上面的报错块）。

---

## 第 5 天：调优（止损线：最多 4 小时）+ 论文主体

调优从开工起算，**最多 4 小时**。到点不管结果多好看，停在当前最好，去写论文。

### 🤖 发给 AI：查逻辑断点

```
这是我论文目前的稿子（还没写完，空的节先空着）：
[贴论文]
请找出逻辑断点：哪里跳步了、哪里上一节说了下一节没用上、哪里的结论和实验对不上。
只列问题，不用帮我写。
```

---

## 第 6 天：论文收尾 + 代码一键复现

代码整理到别人拿到就能跑：依赖、数据路径、运行步骤写清楚。

论文收尾后、定稿前——**强制反对③**：

### 🤖 发给 AI：论文强制反对

```
这是我的论文定稿前最后一版：
[贴论文]
请挑三个毛病：逻辑、表达、结论和实验的对应关系。只挑毛病。
```

### 🤖 发给 AI：提交清单逐项对

```
这是官方提交要求和我列的自查清单：
[贴清单]
请逐项告诉我：每一项具体要检查什么、常见的坑是什么。
```

---

## 第 7 天：提交（10/30 20:00 截止）

清单：论文（格式检查）、代码（可运行 + 说明）、**AI工具使用详情.pdf**（官方要求，不交或漏声明 = 取消评奖资格）、报名信息核对。

```
【决策卡】提交前最终确认
论文、代码、AI工具使用详情.pdf 都齐了，格式都查过
Codex 反对意见（记录一行）：
自己点通过：□
```

点通过，然后上传。

> 💡 加分菜单：留 2 小时空档专门处理"意外"——上传失败、格式错乱、文件超时。截止前最后两小时最容易翻车。

### 🤖 发给 AI：提交前自检

```
今晚 20:00 截止提交。这是我的最终提交内容目录：
[贴目录或截图列表]
请当评委最后过一遍：格式、完整性、AI工具使用详情是否合规。
```

---

## 提交后

初赛前 10% 进复赛（12/4 – 12/11）。进了，复赛前会有新的向导；没进，花一小时写复盘（哪个环节最乱、哪条止损线救了你或者没救成），下次用得上。
