# A1 路线：有基础 × 三人分工

你们三个都打过建模比赛，流程不用教。这条线只解决一件事：**配合别乱**，顺便帮你们加分。

AI 在这条线里不替你们做决策。它的活只有两个：进度提醒、利弊分析。决策永远是你们的。

每次用 AI 记一笔：工具、问了什么、怎么用的。最后要交《AI工具使用详情.pdf》，漏报等于没报。

---

## 赛前：立三条规矩

找一个晚上，三个人花 20 分钟，把这三条定下来：

1. **每天碰头一次，15 分钟**，时间固定（比如每晚 21:00）。只讲三件事：我做了什么、卡在哪、明天要什么。
2. **大决策过决策卡**，全队点一下通过。这张卡只在三个时刻出现：选题、换题、提交前确认。平时不用。
3. **卡住 2 小时就喊 AI**。别死磕，把卡点发给 AI（第 4 天的提示词块就是干这个的）。

同时把工具备齐：一个共享文档（分工表和决策卡都写里面）、论文模板、AI 工具。

> 💡 加分菜单：翻出去年赛题的获奖论文，挑一篇，记一个"评委看了会亮眼"的方向。不抄，只记方向。

### 🤖 发给 AI：赛前试走一遍流程

```
我是参加 MathorCup 大数据竞赛的选手，队里三个人都有建模比赛经验，今年赛题还没公布。
这是去年赛题：[贴赛题]
请带我们模拟走一遍流程：从选题、建模、编程到写论文，每一步该做什么、产出什么、大概花多少时间。
我们想提前熟悉配合节奏，不用真的做题。
```

---

## 第 1 晚：选题（10/23 18:00 赛题公布）

赛题公布后，先别讨论。**每个人独立读题 3 小时**，写下自己的倾向和理由。讨论之前就讨论，容易被第一个开口的人带跑。

3 小时后碰头：轮流说倾向，说完把三份理由发给 AI（见下）。

**决策卡①：选题**

```
【决策卡】选题
决策内容：选 ____ 题，因为 ____
有保留意见的写一行，没有就往下走
全队通过：□
```

全队点一下"通过"，选题才生效。中途想换题也一样——过决策卡，全队点一下通过。

> 💡 加分菜单：看官方评分标准（论文、可运行代码、泛化性能、创新性），挑一个你们三个都认可的评分点，把差异化做在它上面，写进选题理由。

### 🤖 发给 AI：选题利弊分析

```
我们三个人各自读了赛题，这是三份选题倾向和理由：
1. [贴第一份]
2. [贴第二份]
3. [贴第三份]
请给每一份做利弊分析：数据好不好处理、模型可不可行、写论文的坑在哪。
不要给结论，不要推荐哪一题，我们自己做决定。
```

---

## 第 2 天：建模线开工

拆子任务，写进共享文档，谁的名字谁负责。晚上碰头照三条规矩来。

### 🤖 发给 AI：风险提示

```
这是我们今天的进度和明天的计划：
[贴共享文档里今天更新的部分]
请找出风险点：哪些地方可能比想象的花时间、哪个人手上的活最可能卡住。
只列风险，不用给方案，我们明天碰头会讨论。
```

---

## 第 3 天：模型敲定，编程线并行

今天要把模型方案定死。定之前把方案发给 AI 挑毛病（见下）。之后谁再想改模型，就是换题级别的事，要过决策卡。

### 🤖 发给 AI：模型挑刺

```
这是我们定稿前的建模方案：
[贴方案]
请在三个角度挑毛病：数据有没有漏洞、模型假设站不站得住、评委可能会问什么。
挑完毛病我们改，改完再定稿。
```

> 💡 加分菜单：同一个指标，多给评委一个对比视角。比如不只报准确率，还报"和朴素模型的提升幅度"——评委看得见你的模型到底值多少。

---

## 第 4 天：编程主攻，论文线开写

论文不要堆到最后两天。今天把论文框架搭起来，方法部分边做边写。

### 🤖 发给 AI：代码报错

```
代码报错，报错信息：
[贴报错]
相关代码：
[贴代码]
我们用了什么数据、想干什么：[一句话]
请先说人话解释为什么报错，再给修复方法。
```

---

## 第 5 天：模型调优，论文主体完成

### 🤖 发给 AI：查逻辑断点

```
这是我们论文目前的稿子（还没写完，空的节先空着）：
[贴论文]
请找出逻辑断点：哪里跳步了、哪里上一节说了下一节没用上、哪里的结论和实验对不上。
只列问题，不用帮我们写。
```

---

## 第 6 天：论文收尾，代码一键复现

代码整理到别人拿到就能跑：依赖、数据路径、运行步骤写清楚。

### 🤖 发给 AI：提交清单逐项对

```
这是官方提交要求和我们列的自查清单：
[贴清单]
请逐项告诉我：每一项具体要检查什么、常见的坑是什么。
```

---

## 第 7 天：提交（10/30 20:00 截止）

清单：论文（格式检查）、代码（可运行 + 说明）、**AI工具使用详情.pdf**（官方要求，不交或漏声明 = 取消评奖资格）、报名信息核对。

**决策卡②：提交前最终确认**

```
【决策卡】提交前最终确认
论文、代码、AI工具使用详情.pdf 都齐了，格式都查过
有保留意见的写一行，没有就往下走
全队通过：□
```

全队点一下通过，然后上传。

> 💡 加分菜单：留 2 小时空档专门处理"意外"——上传失败、格式错乱、文件超时。截止前最后两小时最容易翻车。

### 🤖 发给 AI：提交前自检

```
今晚 20:00 截止提交。这是我们的最终提交内容目录：
[贴目录或截图列表]
请当评委最后过一遍：格式、完整性、AI工具使用详情是否合规。
```

---

## 提交后

初赛前 10% 进复赛（12/4 – 12/11）。进了，复赛前会有新的向导；没进，花一小时写复盘（哪个环节最乱、哪张决策卡最难下），下次用得上。
