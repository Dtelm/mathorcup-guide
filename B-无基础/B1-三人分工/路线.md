# B1 路线：无基础 × 三人分工

你们三个都没完整打过建模比赛。这条线和 A 系不一样：**每一步都教，每一步都告诉你为什么**。

AI 在这条线里是**教练**：概念、步骤、推荐模型都可以问它。但有两条官方红线，先记死：

1. **模型和论文的核心内容必须你们自己写**。让 AI 全包，查出来就是取消评奖资格。
2. **每用一次 AI，记一笔**。工具名、问了什么、用了什么——最后要交《AI工具使用详情.pdf》，漏报等于没报。

决策卡（简化版，全队点一下通过），只在三个时刻出现：选题、换题、提交前确认。

你们自己的底线机制就一条：**每天碰头会，每人把今天的活讲给别人听**。讲不清就是掉队了，当场问清楚再散会。

---

## 赛前：三小时扫盲 + 分工

找一个晚上，三小时，照这个顺序过：

**第一小时：建模竞赛是什么**

- 一道数据题，7 天时间，交两样东西：论文 + 代码
- 评分看四项：论文、可运行代码、泛化性能、创新性
- 初赛前 10% 进复赛

**第二小时：三个角色干什么**

- 建模手：管数据和模型——数据怎么处理、用什么模型
- 编程手：把模型跑出来——代码能跑、结果能复现
- 论文手：把全过程写成论文——评委只看这个
- 三个人各认一门，边学边干

**第三小时：AI 怎么当教练 + 分工落定**

- AI 可以问：这是什么概念、这一步怎么做、报错怎么修
- AI 不能替你们做：模型、论文核心内容（官方红线）
- 分工认领，写进共享文档；排 7 天时间表

### 🤖 发给 AI：赛前试走一遍流程

```
我们三个第一次参加 MathorCup 大数据竞赛，都没什么基础，今年赛题还没公布。
这是去年赛题：[贴赛题]
请用最白话的方式带我们模拟走一遍流程：从选题、建模、编程到写论文，每一步该做什么、产出什么、大概花多少时间。
```

> 💡 加分菜单：找一篇去年获奖论文，只看两样东西——目录结构和图表。论文大概长什么样，心里有个数就行。时间不够就跳过。

## 第 1 晚：读题 + 选题（10/23 18:00 赛题公布）

**怎么读题**（三个都做）：

1. 先看数据：有几份数据、多少行多少列、长什么样
2. 再看要求：题目要你预测什么、给出什么结果
3. 最后看评分标准：官方想考你什么

读 2–3 小时，各自写"我最想选哪题、为什么"，碰头说。

**怎么选题**（小白就一条）：**选数据最好处理的那题**，不选最酷的。你们的任务是走完整个流程，不是赢创新奖。

### 🤖 发给 AI：选题利弊分析

```
我们第一次参赛，独立读了赛题，三份倾向和理由是：
1. [贴第一份]
2. [贴第二份]
3. [贴第三份]
请用最白话的方式给每一份做利弊分析，重点回答：哪题的数据最好处理、哪题的坑最少。
不要给结论，不要推荐，我们自己决定。
```

**决策卡①：选题**

```
【决策卡】选题
决策内容：选 ____ 题，因为 ____
有保留意见的写一行，没有就往下走
全队通过：□
```

---

## 第 2 天：建模（先懂再动手）

**什么是建模**：给数据找一个"算法"，让它能从已知推出来知。比如用历史销量预测下周销量。

小白起步就三步：

1. 把赛题的问题翻译成一句话：**输入什么，输出什么**
2. 问 AI：这类问题常用哪些模型，各有什么优缺点
3. 挑一个"最常见、教程最多"的，先跑通再说

### 🤖 发给 AI：选模型

```
我们第一次参赛，赛题的要求是：[贴题目要求]
我们的数据长这样：[贴数据的列名和前几行]
请用最白话的方式：
1. 这类问题叫什么类型
2. 常用哪 2-3 个模型，各有什么优缺点
3. 哪个最适合新手、教程最多
```

今晚碰头会：建模手把"输入什么、输出什么、选什么模型"讲给另外两个人听，讲清才算过。

---

## 第 3 天：编程开工 + 论文框架

**编程手的规矩：代码先跑通，再谈其他。**能用 AI 生成的代码就用，跑通之后自己一行一行读一遍，能说清每行大概干什么（说不清就问 AI）。

**论文手今天搭框架**。论文五节，照着写：

1. 摘要（最后写）
2. 问题重述（题目说了什么）
3. 模型建立（你们用了什么模型、为什么）
4. 求解与结果（怎么算的、结果多少）
5. 结论（做到了什么、还有什么没做到）

### 🤖 发给 AI：代码报错

```
代码报错，报错信息：
[贴报错]
相关代码：
[贴代码]
我们想干什么：[一句话]
请先说人话解释为什么报错，再给修复方法。我们是新手，请讲细一点。
```

---

## 第 4 天：编程主攻 + 论文开写

编程手主攻：把模型跑出结果，结果存下来，每一步都留代码和说明。

论文手开写：先把"问题重述"和"模型建立"两节写出来。写不出来的地方标红，问 AI。

### 🤖 发给 AI：论文卡壳

```
我们第一次写建模论文，卡在这一节：[贴卡住的部分]
请用最白话的方式解释这里应该写什么，并举一个简短的例子。
我们想自己写，你只教，不代写。
```

---

## 第 5 天：调优 + 论文主体

**什么是调优**：模型已经能跑了，让它结果更好一点。

小白规矩：**调优最多半天**。到点不管结果好不好，停下来去写论文——论文写不完比模型差一点更致命。

### 🤖 发给 AI：查逻辑断点

```
这是我们论文目前的稿子（还没写完，空的节先空着）：
[贴论文]
请找出逻辑断点：哪里跳步了、哪里上一节说了下一节没用上、哪里的结论和实验对不上。
只列问题，不用帮我们写。
```

---

## 第 6 天：论文收尾 + 代码复现

**什么是复现**：别人拿到你们的代码，照着说明跑一遍，能得到和你们一样的结果。

编程手做两件事：代码加注释、写一个"怎么跑"的说明（环境、数据放哪、按什么顺序跑）。

论文手把五节合起来，摘要最后写（等结果都定了再写）。

---

## 第 7 天：提交（10/30 20:00 截止）

提交清单，逐项过：

1. 论文（格式按官方要求）
2. 代码（能跑 + 说明）
3. **AI工具使用详情.pdf**（官方要求，不交或漏声明 = 取消评奖资格）
4. 报名信息核对

**决策卡②：提交前最终确认**

```
【决策卡】提交前最终确认
论文、代码、AI工具使用详情.pdf 都齐了，格式都查过
有保留意见的写一行，没有就往下走
全队通过：□
```

**留 2 小时空档**：上传失败、格式错乱都发生在这两小时。建议 18:00 前上传完毕，之后只改不重传。

### 🤖 发给 AI：提交前自检

```
今晚 20:00 截止提交。这是我们的最终提交内容目录：
[贴目录或截图列表]
请当评委最后过一遍：格式、完整性、AI工具使用详情是否合规。
```

---

## 提交后

初赛前 10% 进复赛（12/4 – 12/11）。没进也正常——你们第一次参赛，把七天走完就是胜利。花半小时写复盘：哪个环节最蒙、哪个队友差点掉队，下次用得上。
