# B2 路线：无基础 × 独立完成

你第一次参赛，而且只有你一个人。这条线把你从头带到尾，AI 同时当两样东西：**教练**（教你每一步怎么做）+ **第二双眼睛**（帮你看代码、查问题——你没有队友，AI 是你的全部外援）。

两条官方红线，先记死：

1. **模型和论文的核心内容必须你自己写**。让 AI 全包，查出来就是取消评奖资格。
2. **每用一次 AI，记一笔**。工具名、问了什么、用了什么——最后要交《AI工具使用详情.pdf》，漏报等于没报。

决策卡（简化版：决策一行 + 自己点通过），只在三个时刻出现：选题、换题、提交前确认。

你的止损线，记死：

- 选题：第 1 晚 23:00 前定下来
- 建模：第 3 天中午 12:00 前有能跑的模型
- 调优：最多 3 小时
- **总保险：第 5 天还没跑通模型，切"保交卷模式"——用最简模型跑出结果，剩下时间全给论文**

到点没成，走止损三步：换做法 → 降级目标 → 砍掉。止损不是认输，是把时间花在能交卷的地方。

---

## 赛前：三小时扫盲 + 半小时排表

**第一小时：建模竞赛是什么**

- 一道数据题，7 天时间，交两样东西：论文 + 代码
- 评分看四项：论文、可运行代码、泛化性能、创新性
- 初赛前 10% 进复赛

**第二小时：一个人怎么排 7 天**

- 三个人能并行，你只能串行：建模 → 编程 → 论文，一段一段来
- 每段提前写死"最多花多久"，写进时间表——这就是你的止损线

**第三小时：AI 当教练 + 第二双眼睛**

- 可以问：这是什么概念、这一步怎么做、报错怎么修
- 不能替你：模型、论文核心内容（官方红线）
- 每天固定时间把当天的代码和论文发给 AI 检查——你的第二双眼睛

**最后半小时：排时间表**

```
【7天时间表 + 止损线】
第1晚: 读题+选题（止损线：23:00 定下来）
第2天: 建模（止损线：第3天中午12:00 有能跑的模型）
第3天: 建模收尾+编程开工+论文框架
第4天: 编程主攻+论文开写
第5天: 调优（止损线：最多3小时）+论文主体
第6天: 论文收尾+代码复现
第7天: 提交
总保险：第5天还没跑通模型 → 切保交卷模式
```

### 🤖 发给 AI：赛前试走一遍流程

```
我第一次参加 MathorCup 大数据竞赛，没什么基础，而且是一个人参赛，今年赛题还没公布。
这是去年赛题：[贴赛题]
请用最白话的方式带我模拟走一遍流程：从选题、建模、编程到写论文，每一步该做什么、产出什么、大概花多少时间。
一个人做，我想提前知道哪里最容易超时，不用真的做题。
```

> 💡 加分菜单：找一篇去年获奖论文，只看目录结构和图表，心里有个数就行。时间不够就跳过。

---

## 第 1 晚：读题 + 选题（10/23 18:00 赛题公布）

**怎么读题**：先看数据（几份、多少行多少列）→ 再看要求（要你预测什么）→ 最后看评分标准。

**怎么选题**：**选数据最好处理、最简模型能跑通的那题**。你只有一个人，最酷的题留给三人的队伍去抢。

读 2–3 小时，写下倾向和理由。

### 🤖 发给 AI：选题利弊分析

```
我第一次参赛，一个人，独立读了赛题。我的倾向和理由是：
[贴你的倾向和理由]
请用最白话的方式做利弊分析，重点回答：哪题的数据最好处理、哪题用最简单的模型就能跑通。
不要给结论，不要推荐，我自己决定。
```

```
【决策卡】选题
决策内容：选 ____ 题，因为 ____
自己点通过：□
```

**23:00 止损线**：到点还没定，直接选数据最好处理的那题。

---

## 第 2 天：建模（止损线：第 3 天中午 12:00）

**什么是建模**：给数据找一个"算法"，让它能从已知推出来知。

三步：

1. 把赛题问题翻译成一句话：**输入什么，输出什么**
2. 问 AI：这类问题常用哪些模型、哪个最适合新手
3. 挑"最常见、教程最多"的那个，先跑通再说

### 🤖 发给 AI：选模型

```
我第一次参赛，赛题的要求是：[贴题目要求]
我的数据长这样：[贴数据的列名和前几行]
请用最白话的方式：
1. 这类问题叫什么类型
2. 常用哪 2-3 个模型，各有什么优缺点
3. 哪个最适合新手、教程最多
```

---

## 第 3 天：建模收尾 + 编程开工 + 论文框架

**中午 12:00 止损线**：到点还没有能跑的模型，走止损三步——换更简单的模型 → 用现成基线跑通 → 直接用赛题附带的基线（如果有），把时间让给论文。

下午编程开工：**代码先跑通，再谈其他**。AI 生成的代码跑通后，自己一行一行读一遍，说不清就问 AI。

晚上把论文五节框架搭起来：摘要（最后写）/ 问题重述 / 模型建立 / 求解与结果 / 结论。

### 🤖 发给 AI：代码报错

```
代码报错，报错信息：
[贴报错]
相关代码：
[贴代码]
我想干什么：[一句话]
请先说人话解释为什么报错，再给修复方法。我是新手，请讲细一点。
```

---

## 第 4 天：编程主攻 + 论文开写

编程：把模型跑出结果，结果存下来，每步留代码和说明。

论文：先把"问题重述"和"模型建立"写出来，写不出的地方标红问 AI。

### 🤖 发给 AI：论文卡壳

```
我第一次写建模论文，卡在这一节：[贴卡住的部分]
请用最白话的方式解释这里应该写什么，并举一个简短的例子。
我想自己写，你只教，不代写。
```

---

## 第 5 天：调优（止损线：最多 3 小时）+ 论文主体

**什么是调优**：模型已经能跑了，让它结果更好一点。

调优从开工起算最多 3 小时，到点不管结果好不好，停下来写论文。

**总保险（今天检查）**：如果到现在模型还没跑通——切**保交卷模式**：用最简模型（哪怕就一个平均值预测）跑出结果，剩下时间全给论文。交得上一份完整的论文，比交不上一份花哨的模型强一百倍。

### 🤖 发给 AI：查逻辑断点

```
这是我论文目前的稿子（还没写完，空的节先空着）：
[贴论文]
请找出逻辑断点：哪里跳步了、哪里上一节说了下一节没用上、哪里的结论和实验对不上。
只列问题，不用帮我写。
```

---

## 第 6 天：论文收尾 + 代码复现

**什么是复现**：别人拿到你的代码，照着说明跑一遍，能得到和你一样的结果。

做两件事：代码加注释、写一个"怎么跑"的说明（环境、数据放哪、按什么顺序跑）。

论文五节合起来，摘要最后写。

### 🤖 发给 AI：论文检查（第二双眼睛）

```
这是我的论文定稿前最后一版：
[贴论文]
请挑三个毛病：逻辑、表达、结论和实验的对应关系。只挑毛病，不用帮我改。
```

---

## 第 7 天：提交（10/30 20:00 截止）

提交清单，逐项过：

1. 论文（格式按官方要求）
2. 代码（能跑 + 说明）
3. **AI工具使用详情.pdf**（官方要求，不交或漏声明 = 取消评奖资格）
4. 报名信息核对

```
【决策卡】提交前最终确认
论文、代码、AI工具使用详情.pdf 都齐了，格式都查过
自己点通过：□
```

**留 2 小时空档**：上传失败、格式错乱都发生在这两小时。建议 18:00 前上传完毕，之后只改不重传。

### 🤖 发给 AI：提交前自检

```
今晚 20:00 截止提交。这是我的最终提交内容目录：
[贴目录或截图列表]
请当评委最后过一遍：格式、完整性、AI工具使用详情是否合规。
```

---

## 提交后

初赛前 10% 进复赛（12/4 – 12/11）。没进也正常——你一个人第一次参赛，把七天走完就是胜利。花半小时写复盘：哪个环节最蒙、哪条止损线救了你，下次用得上。
